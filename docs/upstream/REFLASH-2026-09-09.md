## SPI diagnostic snapshot

After the failed captures, with the stream stopped, read-only SWD inspection
found PIO0/SM0 PC `1`, instruction `0x2009` (`wait 0 gpio 9`), FIFO level zero,
and DMA write address `0x20008000` at the ring base. The GPIO input snapshot
was `0x303`: GP8 high, GP9 high, GP10 low. This snapshot is not an electrical
timing measurement. The retained PIO state indicates a wait for CS assertion;
it does not establish whether CMX918 output is absent or disconnected/miswired.

Register locations were taken from pinned `rp-pac` 7.0.0, RP235x `mod.rs`,
`pio.rs` and `sio.rs`: PIO0 base `0x50200000`, SM0 PC/instruction at offsets
`0xd4/0xd8`, FIFO status/debug/level at `0x04/0x08/0x0c`, DMA0 at `0x50000000`,
and SIO GPIO input at `0xd0000004`. Instructions are in `firmware/src/capture.rs`.
